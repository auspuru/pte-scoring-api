# Describe Academy coaching in the PTE portal

Describe Image results now include the Academy's **Keep / Change / Try** feedback: an exact quoted strength, up to two specific edits, a supported personalised revision and one next recording exercise. A strong response receives no invented correction. Coaching prioritises accuracy, selection, grouping, relationships and expression; conclusions and exhaustive intermediate figures remain optional.

The integration adapts `auspuru/Describe`'s `backend/openai-coach.js` full-response coaching instructions and validation, retrieved on 20 October 2026. The pure `scoring-policy.js` (`meaning-first-40s-v1`), `response-selection.js` (`key-features-40s-v1`) and `image-claims.js` helpers are copied into `describe-image-feedback/`. `describe-image-feedback.js` adapts the portal's question metadata and validates the coaching result. Future Academy changes require deliberately updating this snapshot; this is not a live cross-service proxy.

The portal's current content assessment request also requests coaching. It retains its existing server-side provider, content-score contract and audio assessor. No new key, account connection, Academy network request or extra coaching request is required for a normal submission. The additional response text uses provider tokens. A failed coaching section does not trigger another call or discard a verified score. Quotes, factual references, numerical rewrites, source contradictions and unrealistic graph-detail demands are checked before coaching is displayed; all rendered text is escaped.

Saved results gain an explicit **Get image feedback** or **Update image feedback** action. This uses the saved transcript, preserves its original content and audio scores, and does not transcribe, upload or assess audio again. Current saved coaching is reused. Coaching refresh remains subject to existing attempt ownership and rate limits. A review is reused within a request if an optimistic database update retries. Unavailable coaching is reported without claiming the feedback was updated.

Other speaking tasks keep their existing prompts and feedback. Recordings, question IDs, result history and storage tables are unchanged. This does not convert raw practice marks to Pearson scores or infer pronunciation from text.

Validation covers a single combined request, unsupported quotes and numerical rewrites, optional-detail demands, source-based corrections, stored-score preservation, failed-refresh recovery, account isolation, cached refreshes, rendered escaping and a real client refresh without re-recording. Provider responses are simulated in tests. Actual model quality and signed-in microphone interaction require a live account review; no paid provider call was made solely for testing.
