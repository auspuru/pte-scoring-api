# Explanatory essay feedback

Essay Practice, Writing Mock essay results and the synthetic review preview now show the seven awarded marks beside their explanations, without requiring an expansion. The shared table also reads saved legacy results without rescoring them. The primary result view replaces its duplicate metric cards and generic verdict with the score, word count and actual assessment. Structured issues use student-facing titles, exact wording, explanations, an action and the trait-specific effect. Language corrections retain original-to-corrected examples. Full Grammar marks explicitly describe the existing meaning-based practice policy rather than implying error-free writing.

The 26-point rubric, Form boundaries, spelling rules and Grammar policy are unchanged. `essay-unified-2.6` separates fresh assessments from earlier in-memory caches. Every changed immutable script and stylesheet reference is fingerprinted, including the deferred Writing Lab client. Saved attempt scores and text remain untouched.

The essay provider now uses `ESSAY_CLAUDE_MODEL`, defaulting to `claude-sonnet-4-6`, independently of the general `CLAUDE_MODEL`. Both initial readers use this essay model; the existing stronger-review override remains available. SWT and other task providers are unchanged. Feedback guidance asks for specific strengths, exact corrections, qualified readings of ambiguous wording, credit for everyday causal connections, and separate treatment of expression and Content. The factual support audit receives the same distinctions. Existing quotation validation, blind review, final reconciliation, shared deadlines and call limits remain in force. Existing structured-feedback cohort settings are unchanged.

## Verification and limits

All 1,158 automated tests and offline calibration checks passed. Added regression coverage checks visible explanations for both contracts, actual result-view ordering, unchanged awarded/gated marks, escaping, long text, correction deduplication and the dedicated essay-model default. These contract tests do not prove semantic scoring accuracy.

Two live end-to-end checks used the local assessment service and the existing production Claude proxy without saving student attempts. The first pass returned 20/26 for the 208-word late-submission essay and 21/26 for the 206-word television essay, each in approximately 93–94 seconds using four Sonnet calls. The television result overstated an absence of reasoning about late-night viewing and sleep. The late-submission result treated an awkward opening as a Content weakness. A second pass after the causal/trait instructions returned 21/26 for the late-submission essay in about 90 seconds, but still retained the expression-based Content criticism. The television recheck returned 19/26 in about 93 seconds; it credited the sleep explanation while continuing to criticise the social-interaction point, and its Grammar/Language marks varied. These are known semantic limitations, not evidence that stronger Claude alone has solved scoring interpretation. Totals are not constrained to earlier manual estimates, and no score floor is introduced.
