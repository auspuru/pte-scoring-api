IDs use the prefix `sgd-user-20261030-`. Source image filenames are retained
in `content/user-sgd-oct30.json`. Transcription preserves the supplied dialogue,
narration and speaker order. Unrelated screenshot UI messages are excluded.
The conference discussion identifies Speaker 3 as the tutor, not a third student.
The two AI topics are distinct: general academic use versus proofreading.

Each question includes connected reference points and a third-person sample.
Reference summaries preserve disagreements rather than inventing consensus.
Preparation remains 10 seconds and response time remains 120 seconds.

The bundled MP3s contain the narration and every supplied turn. Each of the
three labels has a stable, distinct voice, including the non-cyclic turn order
in questions 01 and 07. Manifest checks bind the audio to the full transcript,
speaker mapping, turn order and duration. No runtime speech-generation call is
needed. Regenerate only with `scripts/generate-user-sgd-audio.py`; this is an
authoring operation, not an install or production-start operation.

All fifteen recordings now use a contrasting three-voice profile: English,
Scottish and Northern Irish voices with different tones. A voice is assigned to
each speaker label once and stays with that speaker even when turn order changes.
The opening narration is followed by a short pause before the discussion begins.
Question-bank and speaking-mock audio URLs use new cache versions so students
receive the updated recordings.

Synthetic voices use Piper's VCTK medium model. Source, model checksums,
University of Edinburgh CSTR VCTK dataset attribution, CC BY 4.0 licence and
audio modifications are recorded in `content/speaking-audio/sgd-voice-source.json`.
