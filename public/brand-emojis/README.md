# PTE Scoring API Brand Emoji Pack

A custom scoring-product emoji/icon set for the IPT Brisbane PTE platform.

## Brand system

This pack follows the existing `public/ipt-tokens.css` palette:

- Deep blue: `#173B63`
- Primary blue: `#205080`
- Supporting blue: `#2D6CA5`
- Light blue: `#E9F2FA`
- IPT red: `#C53030`
- Light red: `#FBE9EA`
- Ink: `#18202A`
- White: `#FFFFFF`

Each asset uses a 128×128 SVG viewBox, simplified geometry and thick outlines so it remains readable at emoji/reaction size.
